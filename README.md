A soft, futuristic cyberpunk personal portfolio webpage designed and developed for **Laverne Rollison**. Featuring dark-mode glassmorphism cards, glowing ambient gradients, and soft pastel neon accents (pink, lavender, and cyan).

---

## Features & Visual Style

- **Soft Cyber Aesthetics:** Ambient glowing background orbs with smooth floating animations.
- **Glassmorphism UI:** Translucent dark card layouts with fine glowing borders.
- **Responsive Layout:** Optimized for desktop, tablet, and mobile viewing.
- **Pure CSS & HTML:** Lightweight and fast load speeds with zero JavaScript dependencies.
- **Typography & Icons:** Integrated with Google Fonts (*Space Grotesk* & *Outfit*) and Font Awesome 6 icons.
