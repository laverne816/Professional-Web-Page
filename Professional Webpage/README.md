# Laverne Rollison — Personal Portfolio

A sleek, soft-futuristic personal webpage designed for Laverne Rollison. Features modern glassmorphism aesthetic, soft neon pink and lavender accents, fully responsive layouts, and clean CSS styling.

## Folder Structure

- `index.html`: Main HTML file structure.
- `style.css`: Stylesheet containing color palettes, glowing ambient animations, layout grids, and responsiveness.
- `README.md`: Project documentation and details.

## Features

- **Soft Futuristic Visuals:** Neon pink, cyan, and lavender highlights paired with dark glassmorphism cards.
- **Responsive Layout:** Formatted seamlessly for desktop, tablet, and mobile browsers.
- **No External JS Dependencies:** Lightweight, fast-loading static site architecture.
- **Font Integration:** Google Fonts (Outfit & Space Grotesk) + Font Awesome 6 icons.

## How to Run Locally

Simply double-click `index.html` to open and view the webpage in any modern web browser.
